Agent Workflow 系统的设计目标
1. 透明（Transparency）
→ 所有环节白盒化：上下文、工具、Token、信息流转全部可追溯
2. 自动化（Automation）
→ 执行、验证、恢复、迭代尽可能由 Agent/规则/代码完成
→ 人的角色从执行者变为监督者和决策者
3. 可控性（Controllability）
→ 用户随时可介入、修正、叫停、设边界
→ 自动化程度可调节（全自动 ↔ 半自动 ↔ 手动）
→ 可复现：固定所有随机性来源（模型版本、Prompt 版本、随机种子、数据快照），保证同输入同配置下结果一致。可控不仅意味着"此刻管得住"，也意味着"下次跑还是一样"
4. 直观/可视化（Intuitiveness）
→ 面向所有用户，降低认知负荷
→ 不是给用户看日志，而是给用户看"故事"
