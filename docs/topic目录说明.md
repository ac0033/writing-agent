# topic 目录

`topic/` 存放每篇文章的用户材料与过程产物，属于用户数据，不随仓库发布（已 gitignore）。顶层只放主题目录，不放散落的素材、脚本或状态文件。

每个主题按需使用 `materials/`（原始材料）、`framework/`（提炼与大纲）、`drafts/`（正文）、`review/`（审核）、`run/`（运行脚本与状态）、`output/`（正式输出）。同一主题的历史版本放 `archive/` 或明确的版本目录；版本内部再按材料、稿件、审核和运行记录分类。目录不用预先建空，出现对应内容时再建立。

新材料能归入已有主题就放入对应主题；不属于现有主题则新建主题目录。`writing_prepare_topic` / `writing_start_v2` 会把主题文件生成在 `topic/` 顶层（文件名含日期与随机标识，供任务登记簿按路径和指纹回查）；一篇文章保存后，可把它归入该主题的 `framework/`，但不要在任务仍在运行时移动。
