# 写作规范来源与适配

此目录作为管道运行时的版本化规范，不依赖插件缓存或个人绝对路径。

- systems-thinking.md：来自用户级 systems-thinking/SKILL.md；保留结构、依据与用词纪律，去掉互动确认要求。
- cognitive-receiver.md：来自用户级 cognitive-receiver/SKILL.md；保留具体到抽象、解释背景，互动教学改为博客例子。
- clear-reporting.md：来自 clear-reporting@personal 0.2.0 的 SKILL.md 与 references/workflow.md；保留证据边界与表达复核。
- human-writing.md：项目内后备规范；外部 human-writing 文件存在时作为补充，缺失时不阻断成稿。
- article-writing/SKILL.md：项目技能，集中处理连续论述、选材、范文与阅读质量；文中的改写示例只用于教学对照，不是验收稿。由定框架、写作、内容审核和润色使用。

优先级：事实和作者原意 > 论证与读者理解 > 通用风格规则；适用的用户明确表达要求优先于通用技能。统一由 config.SKILL_ROLES 装配。human-writing 后备规范不能标成外部《活人感写作》全文。
这些是明确裁剪的写作适配版，不宣称执行了原 skill 的完整教学、计算脚本或独立读者检查。
